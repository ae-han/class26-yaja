# 2학년 6반 야자 관리

`index.html`은 기존 신청 화면, `board.html`은 연결이 불안정한 학교 스마트 칠판용 조회 화면입니다.

칠판에서는 `https://ae-han.github.io/class26-yaja/board.html`을 사용합니다. 처음에는 인터넷에 연결해 화면과 자료를 받아야 합니다. 이후 같은 브라우저에서 마지막 자료를 보관하고, 연결이 복구되면 자동 갱신합니다. 정상 연결 시 CIP 중에는 1분, 그 외에는 5분 간격으로 확인하며 연결 실패가 이어지면 최대 5분 간격으로 재시도합니다. ‘지금 갱신’ 버튼으로 즉시 확인할 수 있습니다.

‘오프라인 파일 저장’으로 저장한 HTML은 USB로 옮겨 인터넷 없이 열 수 있습니다. 이 파일에 포함된 신청 자료는 마지막 확인 시각 기준이며, 새 신청은 인터넷 연결 후 반영됩니다. 저장된 자료보다 뒤 날짜는 미확인 상태로 표시합니다. 브라우저 기록·사이트 데이터를 삭제하면 자동 보관한 화면과 자료도 삭제될 수 있습니다. 학교망이 사이트 주소 자체를 막거나 칠판 브라우저가 HTTPS 접속을 지원하지 않으면 저장한 HTML 파일을 사용하거나 칠판에 PC를 연결해야 합니다.

별도 외부 스크립트와 폰트를 사용하지 않으며, Firebase REST 조회만 사용합니다. 보안 규칙과 기존 신청·취소 동작은 변경하지 않습니다. 화면을 받지 못한 최초 접속, 자료를 저장할 수 없는 기기, 조회 오류, 오래된 자료를 서로 구분해 표시합니다.

검증: `node tests/board.cjs`, `node tests/board-sw.cjs`
